# HUBC-Homogenization-Codes

These files are the homogenization scripts used for Howard University Beltsville Campus.
Both files must be in the same directory.
Please pay close attention to the addresses in the scripts to make sure you are pulling data from the correct directories

NOTE: Every station will need different recommended corrections. Please read through "O3S-DQA:Guidelines for Homogenization of Ozone Sonde Data
(Version 2.2: June 2021) Smit et al 2021" to see which ones apply or dont apply for your station

HUBC Homogenization Paper -> Richards, J. A. D., Stauffer, R. M., Kollonige, D. E., Thompson, A. M., Demoz, B., Sakai, R. K., & Flores, A. (2026). Howard University Beltsville Campus ozonesonde record: Data homogenization and uncertainties. Earth and Space Science, 13, e2026EA005120. https://doi.org/10.1029/2026EA005120
